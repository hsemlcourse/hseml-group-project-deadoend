## Описание задачи
**Задача:** Регрессия. Предсказание прибыли (Profit) на основе характеристик транзакции.  
**Датасет:** E-commerce Transaction Data (30,000+ записей). Содержит финансовые показатели, данные о доставке и поведенческие метрики.  
**Целевая метрика:** MAE и R2 Score.

- `data/raw/` — исходные файлы
- `data/processed/` — предобработанные данные
